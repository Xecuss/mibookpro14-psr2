# 配置与工作负载采集

以普通用户在仓库根目录运行。工具通过sudo只读现有debugfs，结果写入本地 `results/`（已被Git忽略），不会修改模块参数、寄存器或显示配置。

## 已知配置

```text
xe.psr2_su_y_alignment=104
```

默认enable_psr=-1、旧max_lines=-1、idle_frames=-1、vrr_ctl_bit26=N；不要留 `xe.enable_psr=1` 强制PSR1。只在已安装带补丁模块时生效。普通鼠标/输入/恢复是否花屏由用户观察，不要求手工定位屏幕行数。

## 一次配置读取

```bash
bash scripts/collect-display-config.sh
```

保存PSR状态、完整显示配置、参数和lockdown状态。DSC可写debugfs接口可能被lockdown拒绝，脚本会跳过，依据新增display-info字段确认当前DSC，不修改安全设置。

## 静止与底部两步

```bash
bash scripts/collect-psr.sh
```

按提示先静止，再把鼠标放在底边左右移动；脚本自动保存配置、3个静置和10个底部快照。当前不是PSR2 enabled会先退出并保留配置，避免误测。快照不等于逐帧轨迹或功耗测量。

## 视频整机功耗：4分钟

```bash
python3 scripts/collect-video-power.py
```

1. 拔掉电源，保留终端和视频浏览器/播放器，关闭其他应用；固定亮度、画质、片段、窗口大小、音量、电源模式和显示模式。
2. 脚本先通过pw-play、paplay或aplay试听短音；只有输入y确认听到才继续，不依赖终端响铃。可用 `--test-beep` 单独试听。
3. 最后Enter后有45秒切回已暂停的视频、取得键盘焦点，将鼠标移到最右下角静止。
4. 单声提示时按空格播放；随后记录240秒/49点。双声提示结束后暂停并回终端填写干扰备注。

记录发声请求和每次采样时间；不能测出实际音频延迟或按键反应时间。PSR仅窗口前后读取，不在采集中轮询GPU；结束sudo过期会在保存功耗后提示认证并另存重试。Ctrl+C会保留已采数据。

## 桌面静置：3分钟

```bash
python3 scripts/collect-idle-power.py
```

45秒准备后采样180秒/37点。使用静止画面、暂停动态壁纸并保持屏幕亮着；亮度、电源或挂起异常会标记结果。这个历史工具没有视频脚本的认证重试；结束状态失败不抹掉功耗，需连同错误复核。无需为发布本仓库重复已完成测试。

## 离线验证

```bash
make check
```

需要Python3、C编译器和make；不会读取本机GPU/电池或播放声音。检查258点数值复算、寄存器范围、10项视频流程模拟，以及原对齐函数stub的21,812,040个区间。后者验证覆盖、边界、无效参数回退与幂等性，不覆盖完整ET/hardware/长期稳定性。
