# 补丁组合

按[series](series)顺序应用0001、0002、0003、0005、0006。编号保留调查中的名称；0004禁用PSR2的quirk未应用，不随当前组合提供。

| 补丁 | 用途 | 当前配置 |
|---|---|---|
| 0001 | 只读debugfs寄存器节选，针对本机pipe A | 状态读取时使用；0x60914不作旧语义解码 |
| 0002 | idle_frames实验参数 | -1，不覆盖计算结果 |
| 0003 | VRR未知bit26实验参数 | N，不要求固定硬件位 |
| 0005 | SU高度门槛，超限走CFF | -1，关闭 |
| 0006 | SU纵向网格及显示信息 | 默认0，推荐显式104 |

保留前三个历史实验参数是为了维持已有实机测试的源码组合，不表示它们已被证明是修复所需。0006不能直接单独套在原始树上，因为参数声明附近包含前面补丁的上下文；用完整series。

公开版仅更新补丁说明，diff正文与测试版一致，[provenance.json](provenance.json)记录原文件与diff的SHA256。原始Linux7.2.9的5个目标文件经应用此组合后，与实际构建树对应文件逐字节一致；Fedora目标模块曾完成构建与实机运行。说明修订没有引入新的内核代码，发布用辅助工具不代表新一轮硬件验收。

[source-files.json](source-files.json)固定5个源文件应用前后的SHA256。应用工具既检查原文件又检查结果，避免把历史补丁的上下文容差当作跨版本适配；不同内核需单独移植。
