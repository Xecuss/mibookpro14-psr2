# 内核升级与7.2.10记录

## 日常更新顺序

本项目没有自动DKMS重建。更新发行版内核后，保留能工作的旧内核；可以继续运行旧内核，为新版本准备匹配的完整源码、kernel-devel、配置和符号表，应用已核对的补丁后重新编译、签名，并安装到**目标版本**的模块目录。

depmod、dracut、签名工具和安装路径都必须指定目标版本，不能默认使用仍在运行的uname -r。具体命令见[构建与回退](BUILD.md)。应用工具按5个原文件的整体SHA256识别已登记源码，再核对应用结果，未登记版本会拒绝，不建议绕过。

重启后先核对运行内核、104启动参数及带补丁模块，再读取一次显示配置，确认PSR2和SU/plane范围。已做过的鼠标、输入、底部和恢复操作直接报告观察即可；无新异常时，不因每次升级就重复网格矩阵、Windows或功耗测试。
